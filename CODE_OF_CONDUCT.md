# Community conduct

Contributors, reviewers and users should be able to participate without harassment.
Be respectful, give specific technical feedback, and allow room for questions and mistakes.
Disagreement is welcome; personal attacks, threats, discriminatory abuse, sexual harassment,
spam and sharing anyone's private information are not.

This applies to repository issues, pull requests and other project-managed discussion.
Maintainers may edit or remove harmful content, restrict participation, or block repeat
offenders. For a moderation request, open an issue with only the minimum public details
needed to identify the affected discussion. Do not repost private or abusive material.
Security vulnerabilities and data exposure should be [reported privately](SECURITY.md).

# Changelog

## v0.2.0-alpha.1 — 2026-10-11

First tagged public source release. Developer tools and manual source permissions are required.

- Guided model selection and Messages self-chat pairing, with a supervised native Mac host.
- Local read tools for Messages, Calendar, Contacts, Mail, Notes, Reminders, Photos and documents.
- Versioned observations, provenance, lexical retrieval and explicit source freshness/coverage.
- Durable conversation/reply state, conservative uncertain-send handling and process recovery.
- Opt-in due-commitment reminders with quiet hours, duplicate suppression and a daily limit.
- Optional iPhone context sync and local Apple/MLX phone conversation infrastructure.
- Mac packaging metadata fix, indexed refresh performance fix, local Calendar dates and bounded
  optional Contacts startup reads.
- Shared concise reply guidance and cleanup for observed leaked model markup.
- Versioned source archives, SHA-256 checksums, privacy/security/contributor guidance and release checks.
- CLI startup test state isolated from an existing assistant on the developer's Mac.

See [release notes](docs/releases/v0.2.0-alpha.1.md) for evidence and known limitations.
